This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).
This utilizes tailwindCSS to work on multiple screens.

Learning management system that allows teacher account creation and creation of spatial visualization courses. Students can be added to courses 
Built specifically for Irish community college (k-8) school contexts; can be expanded to other contexts.

Full demonstration: https://www.youtube.com/watch?v=tDV6CiMCrXk
